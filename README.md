# نیمبو

سایت بوت‌کمپ نیمبو: یک صفحه با سه تب — **فاز صفر**، **نقشه‌ی بوت‌کمپ** و **برنامه‌ی هفتگی** —
به‌همراه یک کنسول ادمین و یک پنل کادر برای باز کردن هفته‌ها و ثبت امتیازها.

## دو حالت

| حالت | کجا | نقشه از کجا می‌آید | کنسول ادمین |
|---|---|---|---|
| **استاتیک** | GitHub Pages | از `src/content/bootcamp.js` داخل باندل | ندارد |
| **زنده** | داکر روی سرور خودت | از API | دارد |

## اجرا روی سیستم خودت

```bash
npm install
npm run dev            # فرانت روی حالت استاتیک
```

API جدا بالا می‌آید:

```bash
cd server
npm install
npm start              # روی PORT، پیش‌فرض ۸۰۸۰
```

بدون `ADMIN_PASSWORD` و رمز کادر، API بالا می‌آید ولی هر ورودی را رد می‌کند — برای دیدن
صفحه‌ها کافی است، برای کار با کنسول نه.

## اجرا روی سرور

با داکر، و اگر روی اینترنت است با HTTPS. مرحله‌به‌مرحله در **[RUNNING.md](RUNNING.md)** آمده:
متغیرهای `.env`، بالا آوردن با `docker compose`، گرفتن گواهی با Caddy، پشتیبان‌گیری و بازگردانی.

```bash
cp .env.example .env   # ADMIN_PASSWORD و SESSION_SECRET و رمزهای کادر را عوض کن
docker compose up -d --build
```

## ساختار

```
src/          فرانت (React + Vite)
  content/    متن برنامه: هفته‌ها، افراد، معماری، برنامه‌ی هفتگی
  pages/      فاز صفر، نقشه، هفته، کادر، ادمین
  components/ اجزای صفحه
  hooks/      خواندن نقشه و تایم‌لاین و رویدادهای هفته
server/       API نقشه (Express) + وضعیت روی دیسک در /data
Caddyfile     فقط HTTPS: گواهی از Let's Encrypt و هدایت http به https
```

تاریخ شروع فاز صفر در `src/config.js` است؛ مأموریت روز N در `startDate + (N-1)` روز باز می‌شود.

## ساخت نسخه‌ی نهایی

```bash
npm run build          # خروجی در dist/
```
